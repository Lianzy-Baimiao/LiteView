# 更新日志

各版本用户能看到的变化，新的在前。完整的发布说明（下载、校验、已知限制）见各版本的 [GitHub Release](https://github.com/Lianzy-Baimiao/LiteView/releases)。发新版时加到这里最上面；README 只放这个文件的链接。

## [v1.11.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.11.0)（2026-11-14）

- 「设置 → 常规」新增「多窗口模式」（默认关）：打开后每打开一个图片文件都开一个新窗口，可以同时看几张（[#8](https://github.com/Lianzy-Baimiao/LiteView/issues/8)）；关着时照旧都在已经开着的窗口里打开。改了马上生效；开着几个窗口时在其中一个里关掉，之后打开的图交给这个窗口。
- 多窗口时新窗口往右下错开一点（Windows），不会正好盖住前一个；在资源管理器里多选几张回车也一样。
- 开着几个窗口时，各个窗口改的设置都会保留：关窗口时只存这个窗口改过的项，不再把别的窗口改的设置（包括关掉多窗口）改回去。

## [v1.10.1](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.10.1)（2026-11-09）

- 修复动图播放时点开播放速度菜单，鼠标一移上去菜单就消失的问题（[#7](https://github.com/Lianzy-Baimiao/LiteView/issues/7)）。工具栏的比例菜单也一样：往上移到 25% 这些预设上，不再连工具栏一起收起。
- 工具栏的比例、播放速度菜单开着时按 Esc 只关菜单，不再直接关掉 LiteView。
- 编辑时菜单（旋转、颜色、字体等）开着，点图片只关菜单，不会顺手在图上画一笔。
- 升级安装时，图片关联没有变化就不再让资源管理器刷新所有文件图标。

## [v1.10.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.10.0)（2026-11-08）

- 排序新增「跟随资源管理器」（Windows），并设为默认：从资源管理器打开图片时，上一张、下一张和那个窗口里的顺序一样，按什么排、升序降序、分组都照它。每次从资源管理器打开图片都重新读，在资源管理器里改了排序再打开一张，就按新的顺序（[#5](https://github.com/Lianzy-Baimiao/LiteView/issues/5)）。
- 找不到开着这个文件夹的资源管理器窗口时（比如从微信、桌面、搜索结果打开），按文件名。想固定按修改时间、大小或类型，在「设置 → 查看 → 排序」照旧选那一项。
- 资源管理器里筛选过时，它显示的图按它的顺序排在前面，其余的按文件名接在后面。
- 升级后，排序还是默认（文件名、升序）的换成「跟随资源管理器」；选过别的排序的保持不变。

## [v1.9.1](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.9.1)（2026-11-06）

- 修复 GIF 动图右键复制或 Ctrl+C 后，粘贴到 QQ 变成静态单帧的问题。现在复制完整 GIF 原文件，保留全部帧、帧延时和循环次数；暂停、逐帧和旋转后复制也保留原动图。
- 复制 GIF 时清除剪贴板中残留的静态图片格式，避免先复制普通图片后再复制 GIF 时粘贴成旧图片。普通图片继续保留透明度和查看时的旋转。

## [v1.9.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.9.0)（2026-11-05）

- 无边框窗口（Windows）里，带透明的图（圆形图标、表情包、抠好的图）透明的地方直接透出桌面，窗口看起来就是图片的形状，没有方阴影和边框；没有透明像素的图照旧。最大化、全屏、编辑时照旧不透明。要以无边框启动才生效：按 Ctrl+B 刚换成无边框时，重新打开 LiteView 后才透出桌面。
- 快速关闭：看图时 Ctrl+W 直接关窗口（全屏时也是）；「设置 → 双击」可选「关闭窗口」。编辑时 Ctrl+W 仍是调整大小（与画图一致）。
- 保存旋转不再损坏文件：APNG 动图不再被存成只剩第一帧的静态图（动图不提示保存旋转）；TGA、QOI 按原格式写回（以前写进去的是 PNG）；PNG 留着颜色配置文件、EXIF、文字说明和 16 位色深；有 EXIF 但没有方向标记的 JPEG 也只改方向标记、画质无损（以前整张重新压缩、EXIF 全丢）；多页 TIFF 只改方向，其它页不动。
- 看图时「另存为」留着颜色配置文件（广色域照片颜色不再变），EXIF 按「保存时保留 EXIF」的设置。
- 设置文件里某一项认不出（比如装回旧版本）时只有这一项回到默认，其它设置照用；以前全部回到默认。
- 在资源管理器里多选几张图回车，或 LiteView 正在启动时又双击图片，都交给同一个窗口，不再多开窗口。
- 改名只改大小写（A.png → a.png）不再提示「已有同名文件」。
- 设置开在单独的窗口里（Windows）：能拖开、改大小，开着设置照样能看图、翻图，改的效果马上看得见；不再被小图片的窗口裁掉。
- 无边框看小图时，右键菜单、确认框、改名框、图片信息、打印对话框不再只露出一角：窗口在图片周围透明地临时变大（图片不动），用完变回原样。
- 缩放时在图片下边显示一下比例（小字，停一会儿就淡出）。

## [v1.8.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.8.0)（2026-11-02）

- Windows 普通窗口中，图片完整显示时可直接左键拖图片移动窗口；图片超出窗口时仍拖动平移，Shift + 拖动可强制移动窗口。普通窗口最大化、全屏和编辑时不启用画布拖窗。判断按图片是否放得下，不以 100% 缩放为界（[#4](https://github.com/Lianzy-Baimiao/LiteView/issues/4)）。

## [v1.7.1](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.7.1)（2026-10-31）

- 文本框好拉了：左右两条边（连同四个角）往外 12 像素都能拉宽，拉左边时右边不动；上下边按住是拖动；指针跟着变。以前只有右边中间一个 7 像素的小点能拉。
- 拉宽文本框、放大看图后，字按新的宽度重排（以前还按放下时的宽度换行，写进图里的也是）。
- 写进图里的文字，用文字工具点它能拿起来接着拖、改字、拉宽，放下时与拿起算一步；那块后来被画过、打过码就拿不起来了。
- 先出过一条短提示后，后面的长提示不再挤成一竖条。

## [v1.7.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.7.0)（2026-10-30）

- 打开 WebM 表情包（Windows）：Telegram 那样带透明的 VP9 动图，用系统的「VP9 视频扩展」解码，透明的地方显示棋盘格；翻文件夹、打开对话框都认 .webm。
- SVG 放大超过 1:1 不再发虚：停下后按屏幕的像素重画看得见的那块。
- 涂抹画笔顺着拖的方向走（以前总是横的）；框选还是横的。
- 比例菜单的输入框能打字了（以前一点就关、打的字变成快捷键）；无边框窗口在缩放不同的两块屏之间来回后不再变小。
- 竖拍照片（EXIF 转 90°）、16 位图解码更快、更省内存；翻大图文件夹、编辑大图时少占内存。

## [v1.6.1](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.6.1)（2026-10-29）

- 打开、缩小大图时少占内存：JPEG、PNG 等 8 位图直接解到最后的缓冲区里，解码快约三成；从 100% 缩小时一条条算、直接写进结果。4800 万像素的照片翻图时内存最高约 370 → 300 MB，从 100% 缩小一点时约 620 → 450 MB。

## [v1.6.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.6.0)（2026-10-29）

- 无边框模式（Windows）：Ctrl+B 或右键菜单「窗口 → 无边框」。窗口就是图片的大小：滚轮缩放时窗口跟着变、换图时变成新图的大小；拖图片移动窗口，拖边缘改大小时保持比例，鼠标到顶部出现细标题栏。
- 「工具栏放不下时放到图片下面」（默认关，右键菜单「窗口」里开）：无边框窗口比工具栏还窄时，工具栏改在图片下面单独的一条里。
- 窗口置顶；「锁定缩放」对所有图生效（以前只对同尺寸的图）。
- 右键菜单把旋转和翻转、文件、窗口各收进一个子菜单，第一层更短。

## [v1.5.1](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.5.1)（2026-10-28）

- 在缩放不同的两块屏之间拖动时，窗口不再来回变大小、闪烁、拖不动：只在过界时变一次（Windows 11）。
- 商店版在资源管理器里的「类型」重新按格式显示（「JPG 文件」「PNG 文件」），按类型分组不再只剩「LiteView 图片」一组。
- GIF 每次换帧只画一次、时间更准，放动图时 CPU 更低；软件渲染时最多约 60 帧。
- 设置、改名框里按 Ctrl+= / Ctrl+- / Ctrl+0 不再缩放整个界面；商店版各尺寸图标更清楚。

## [v1.5.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.5.0)（2026-10-28）

- 打码新增「涂抹」：像油画笔横着抹过去，画笔、框选都能用。框选时框外是一圈不规则的笔触边，不是整齐的方框；「强度」调笔触宽度。
- 右键菜单的滚动条单独占一列，不再压住文字和快捷键。
- 右键菜单高度跟着窗口：窗口够高时完整显示，放不下才滚动。
- 高分辨率的长 GIF（比如三四十帧以上的 1080p 动图）播放更顺：不再每轮播到中途卡一下，后面的帧也不再变慢。

## [v1.4.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.4.0)（2026-10-27）

- 按住翻页：按住 ← → / PgUp PgDn，或按住工具栏、窗口两侧的翻页按钮连续翻。按下翻一张，0.5 秒后开始，每张显示出来后停 0.3 秒，快速浏览也看得清。
- 「已回到第一张」「已经是最后一张」等翻页提示移到图片正中，字更大、更醒目；连续翻回第一张时多停一会儿。
- 「锁定缩放」从设置移到浮动工具栏（锁形按钮），对比同样尺寸的图更方便。
- 图片信息改从左边滑出，点图片区域就能关。
- 窗口比右键菜单矮时菜单可以用滚轮滚动；右键菜单开着时浮动工具栏和左右按钮不再出来挡住它。

## [v1.3.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.3.0)（2026-10-24）

- 新增打印（Windows）：Ctrl+P 或右键「打印…」打开打印预览，按真实比例显示图片在纸上的位置。可选打印机、纸张、方向、尺寸（适合页面 / 指定尺寸，带 5 寸、6 寸、A4 快捷填写 / 按图片分辨率的实际大小）和份数；默认保持比例、居中、完整打印，不裁切。不调用 Windows 自带的图片打印向导。

## [v1.2.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.2.0)（2026-10-24）

- 内存大幅降低（Windows）：空闲约 30 MB，在文件夹里翻看照片约 35 ~ 45 MB，与照片分辨率、看过几张无关（1.1.0 为 111 MB 和 300 ~ 600 MB）。原图像素只在放大、编辑、复制、另存为时才解码，回到适应窗口几秒后放掉。
- Windows 改用 Direct3D 11 显示，不需要 DirectX 12；显卡不可用时自动改用系统自带的软件渲染。
- 浮动工具栏平时不显示，鼠标移到窗口底部时才出现，看图时不再被打扰。
- 新增「省电模式」（自动 / 60 Hz / 不限）：高刷新率屏上拖动、缩放和动图按 60 帧以上的整数分频绘制，静止时不绘制。
- 标题栏 / 任务栏图标在各种缩放比例下清晰；拖到缩放比例不同的显示器时，图片重新适应窗口。

## [v1.1.0](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v1.1.0)（2026-10-23）

- 修复部分电脑上“点了没反应 / 打开图片没有反应 / 无法启动”：显卡接口初始化失败时自动改用 DirectX 12 或 OpenGL；显卡驱动或叠加软件崩溃、卡住后，下次启动自动换接口；系统中文字体被替换成不兼容的文件时不再退出。全部失败时显示错误提示，不再毫无反应。
- “设置 → 关于”显示当前图形接口和上次遇到的问题（含出错模块），反馈时截图即可。
- VVC 编码的 HEIF、只有图像序列的 HEIF/AVIF 提示“不支持这种格式”，不再误报“文件已损坏”。

## [v0.1.1](https://github.com/Lianzy-Baimiao/LiteView/releases/tag/v0.1.1)（2026-10-16，开发预览版）

- 补齐源文件大小和各解码入口的像素预算检查；资源超限不再通过系统解码回退绕过。
- WebP 可选择无损或有损压缩，有损品质独立设置；默认仍为无损。
- 保存时提示格式的 EXIF / ICC / 透明度限制；保留编辑画布及撤销历史，明确区分保存失败与保存后读回校验失败。
- 修复小尺寸 TIFF 的 ICC 读取、旧后台解码结果覆盖新保存图片，以及退出后空闲解码线程未释放的问题。

预算不是整个进程的内存硬上限；系统解码器内部、SVG 解析/滤镜、GPU 与并行预读仍有独立开销，详见 [PRD](PRD.md) 的 OPT-01。
