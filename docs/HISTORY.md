## 2026-11-14 多窗口模式

[#8](https://github.com/Lianzy-Baimiao/LiteView/issues/8)：希望设置里加「多窗口模式」，打开后能运行多个实例，每张图片在自己的窗口里看。

程序里本来就有 `single_instance`（关掉时每次开新窗口），设置里却没有这一项，只能手改设置文件。手改关掉以后，几个窗口的左上角正好叠在一起，看着像没开新窗口；后关的窗口还会把整个设置文件盖回它自己的那份，先关的窗口改过的设置（包括关掉多窗口）都没了。

- [x] 「设置 → 常规」最后加「多窗口模式」（默认关）和一行说明，存的还是 `single_instance`（取反），旧设置文件不用迁移。改了马上存，不等关掉设置：之后打开的图片是新进程，按文件里的设置决定开不开新窗口。开着几个窗口时在其中一个里关掉：没有别的窗口在接收转来的图，就由这个窗口接收（`single::claim_if_free`；别的窗口占着标记时不留句柄，免得那个窗口关了以后，后来的进程对着一个不接收的窗口空等 6 秒）；还开着以单窗口方式启动的窗口时，照旧交给那个窗口。
- [x] 新窗口错开（Windows）：多窗口时窗口建好、还没显示时，左上角和别的 LiteView 图片窗口（别的进程的、窗口类相同、标题以 LiteView 结尾、没最小化，还没显示的也算）横竖都差不到半步，就往右下错开 32 点；出了工作区就从工作区左上角接着排。几个进程靠命名互斥体一个一个排：启动保护只在前一个画出第一帧之前让后来的等着，同时打开几张时，等完的几个进程会一起建窗口。最大化启动的不错开。
- [x] 几个窗口各存各的：存设置时先读文件现在的内容，只把这个窗口改过的项写进去（和它上次读进来或存过的比；对象一层层比，`window.pos`、`window.borderless` 各算一项）。读、合并、写回之间用按文件路径起名的命名互斥体排队（其它系统用旁边的 `.settings.lock` 锁文件），等 2 秒还等不到就照样存；文件读不出来时整个写。只有一个窗口时，写出来的和以前一样。
- [x] 单元测试：两个窗口先后存，各自改的都在，同一项后存的算，`window` 里的项分开算；文件坏了整个写；错开位置的算法（正好重合、只差几个像素、连着两个位置都有、出了工作区、到处都有窗口时停下）；真的隐藏窗口建在别的窗口位置上，错开到空位，标题结尾或窗口类不一样的不算；运行中换回单窗口只占没人占的标记；在界面里关掉多窗口后这个窗口开始接收，另一个窗口再关掉不抢。单元测试的管道名和标记名带进程号，碰不到正在运行的 LiteView。建 winit 事件循环的测试会把整个测试进程换成按每个显示器缩放，和读真窗口位置的测试同时跑时偶尔读错，这两个测试改成一个一个跑。
- [x] 私有桌面上与 1.10.1 对照（`dist/multiwin-20261114/`，每种两轮）：多窗口时 4 个进程同时启动，或先开 1 个再同时来 3 个，新版 4 个窗口依次错开、没有叠在一起的，1.10.1 四个窗口左上角完全一样；单窗口模式 4 个同时来，两版都只剩 1 个窗口；窗口 B 按 Ctrl+B 换成无边框后关掉、窗口 A 后关，新版设置里无边框还在，1.10.1 被 A 改回了关。在设置窗口里点「多窗口模式」：关掉后设置文件马上变，再打开一张图交给这个窗口；勾上后再打开一张另开一个窗口。设置页中英文截图都放得下。Release 测试 248 项、Windows 与 Linux 的 release Clippy（全 targets、零警告）通过。回归一轮（`round.py`）和 1.10.1 在同一块 160 Hz 主屏上对照：两版都只有两项帧数不过，门槛是按 60 Hz 屏定的（拖动后空闲 40 / 42 帧，缩放动画都是 26 帧，拖动都是 80 帧/秒，WARP 都是 53.3 帧/秒），其余 11 项新版全过。

## 2026-11-09 播放速度菜单一移上去就消失、菜单开着按 Esc 关掉程序（v1.10.1）

[#7](https://github.com/Lianzy-Baimiao/LiteView/issues/7)：动图播放时点开播放速度，菜单很快消失，几乎没法用；暂停时才正常。

- [x] 原因：egui 0.36 的 `Context::any_popup_open()` 只算这一帧已经画出来的弹出菜单。浮动工具栏在画之前用它判断「菜单开着时不收起」，那时工具栏上的菜单还没画，总是 false：鼠标往上移进菜单、离开底部感应区，工具栏 0.15 秒淡出，菜单跟着没了。暂停时播放条另有「暂停且鼠标在窗口里就显示」，所以只在播放时看得出；静态图的比例菜单往上移到 25% 那几项也一样。
- [x] 同一个原因还有两处：看图时的 Esc 在工具栏画之前处理，比例、播放速度菜单开着时按 Esc 直接关了程序（右键菜单在画布里、先画，不受影响）；编辑模式的 `popup_was_open`（关菜单的那一下不在画布上画）在一帧开头取值，那时什么都没画，一直是 false，点图片关掉旋转、颜色、字体菜单时会顺手画一笔。
- [x] `app::popup_open`：egui 记着开着的（`Popup::is_any_open`，上一帧开着、还没关）或这一帧已经画了的，有一个就算开着。工具栏的显示、看图时的 Esc、编辑的 `popup_was_open` 改用它；Esc 先看有没有菜单，有就不吃掉这个键，留给菜单自己关。设置窗口、打印对话框都在画完之后才看，照旧。
- [x] 单元测试（改之前三项都不通过）：按真实顺序点开播放条的速度按钮、把鼠标移进菜单停一会儿，菜单和工具栏都在，菜单关了才收起；菜单开着按 Esc 只关菜单，再按才关窗口；编辑时菜单开着按下鼠标不画，菜单关了照常画。
- [x] 隔离桌面上与 1.10.0 对照（`dist/speed-20261108/`）：播放中的 GIF 移到菜单上还在，点 0.25× 后每帧从 40 ms 变成 160 ms（1.10.0 同样操作时菜单已经没了，还是 40 ms）；Esc 关速度菜单、比例菜单（1.10.0 两种都直接退出）；静态图的比例菜单移到最上面的预设还在；右键菜单按 Esc 两版都只关菜单；编辑时刷子点图片关旋转菜单，1.10.0 留下一个点，新版没有，正常点击和拖动照常画。Release 测试 242 项、Clippy、回归一轮 13/13 通过。

## 2026-11-08 升级安装不再让资源管理器重画所有图标（v1.10.1）

用户 09:30 装 v1.10.0 后资源管理器崩了一次。Windows 只留下 Winlogon「外壳程序意外停止」（这台机器关了错误报告，没有转储）：安装程序检查占用文件时没有关闭任何程序，崩在安装结尾通知资源管理器「文件类型变了」、它重画所有图标的那一刻；当时资源管理器里加载着用户另一个开发中的程序 LiteTray 的任务栏适配器，近两天的十几次重启也都和 LiteTray 的部署对得上。09:34 第二次安装做了同样的通知，没有崩。

- [x] 登记文件关联（安装程序的 `--register`、设置里的「文件关联」）先和注册表里现有的比较，一样就不写；有任何一项变了才通知资源管理器，日志写 `[assoc changed]` / `[assoc unchanged]`。另记一个编译时的图标指纹（`build.rs` 算 `assets/app.ico`，存 `HKCU\Software\LiteView\IconStamp`）：新版本换了图标，路径没变也会通知。升级到含这项改动的版本时因为第一次写指纹，还会通知一次。
- [x] 安装脚本去掉 `ChangesAssociations=yes`：它在安装、卸载结尾再发一次同样的通知，和 `--register` / `--unregister` 自己的通知重复。
- [x] 单元测试在 HKCU 下的临时键里登记（不在 `Software\Classes` 下、不发通知）：同样内容再登记不算变化，少选格式不算变化，换图标、换位置算变化。Release 工作流的安装包生命周期检查加了断言：首次安装通知；用同一构建升级不通知；绿色版接管时通知；少选格式不通知。

## 2026-11-04 整体检查修掉的缺陷、单独的设置窗口、小窗口里的菜单和对话框（v1.9.0）

用户 2026-11-04 让整体查一遍工具的缺陷，看完报告后说「先把缺陷都修复」。都是这次之前就有的：

- [x] 保存旋转毁文件（`save::save_rotation`，修之前用临时程序复现：APNG 6 帧 → 1 帧；.tga 写进 PNG；PNG 的 ICC、EXIF 丢了、16 位 → 8 位；有 EXIF 没方向标记的 JPEG 整张重新压缩、EXIF 和 ICC 全丢，对话框却写着「只改方向标记，画质无损」）。现在按文件内容认格式、写回同一种格式：
  - JPEG：有方向标记就原地改；有 EXIF 没有方向标记时，在 Exif 段末尾加一个带方向的新 IFD0、TIFF 头指向它，原来的各项、缩略图、厂商数据一个字节不动（偏移都从 TIFF 头算）；没有 EXIF 插最小的 Exif 段。段结构读不出、Exif 段会超过 64 KB、多图 JPEG 的 MPF 段在 Exif 前面时不写，提示用另存为。扫描段时遇到填充字节、不带长度的标记都按结构不对处理（以前遇到就当没有 EXIF，可能再插一个）。
  - TIFF：IFD0 有方向标记就原地改；没有就在文件末尾加新 IFD0、文件头指向它，第 2 页起照旧接在后面，像素一个字节不动。BigTIFF 没有方向标记时不写。
  - PNG、BMP、TGA、QOI：按原像素格式解码（16 位还是 16 位）、方向转进像素、按原格式编码。PNG 写回 ICC 和清理过的 EXIF（方向 1），文字、pHYs、tIME（没有 ICC 时还有 gAMA / cHRM / sRGB）从原文件原样搬；XMP 和 exiftool 的 Raw profile 不搬（里面可能还记着旧方向，别的软件会再转一次）。
  - APNG（单帧的也算）、GIF、WebP 等：不提示保存旋转；Ctrl+S 时说「存不回原文件，可以另存为」。格式按 `Info::format`（文件内容），不再看扩展名。
  - 关窗口前保存旋转没存成时不关窗口，提示原因（以前只写日志就关了）。解码器 panic 也只算没存成（可能在界面线程上）。
