# LiteView v1.2.0 — 更省内存，工具栏不再打扰看图

看图、简单编辑和打码，放在一个离线小工具里。本版主要降低 Windows 上的内存占用，并让浮动工具栏只在需要时出现。设置、独立安装版和绿色版的使用方式不变。

## 本版更新

- **内存大幅降低（Windows）**：空闲约 30 MB；在文件夹里按窗口大小翻看照片约 35 ~ 45 MB，与照片分辨率和看过几张无关（1.1.0 分别为 111 MB 和 300 ~ 600 MB，4800 万像素照片约 600 MB）。
  - 每张图解码后只留一张按窗口缩好的画面交给显卡，与准确缩小显示的效果逐像素相同。
  - 原图像素只在放大到看不清、编辑、复制、另存为、设为背景时才解码；回到适应窗口几秒后或换图后放掉。
  - 预读一次只解一张，等当前图显示后才开始。
- **Windows 改用 Direct3D 11 显示**：不再加载 Vulkan / DirectX 12，只需要支持 Direct3D 11 特性级 10.0 的显卡；显卡不可用或驱动在启动时出错，自动改用 Windows 自带的软件渲染（WARP）。画面与 1.1.0 相同。
- **浮动工具栏不再打扰看图**：平时不显示，鼠标移到窗口底部的感应区才淡入，移开即淡出；比例、速度等弹出菜单打开时不收起。
- **省电模式**：“设置 → 常规”新增“自动 / 60 Hz / 不限”，默认自动。静止时不绘制；高刷新率屏上拖动、缩放和动图按不低于 60 帧的整数分频绘制（144 Hz 为 72 帧、160 Hz 为 80 帧），“60 Hz”最多 60 帧，“不限”跟随显示器。
- **其他修复**：
  - 标题栏和任务栏图标在各缩放比例下按实际尺寸绘制，不再发虚。
  - 拖到缩放比例不同的显示器上时，“适应窗口”的图片会重新适应。
  - 启动特别慢时又双击图片，第一个窗口画出来后不再被误记为显卡失败（否则以后每次都会用软件渲染）。

## 验证与发布门禁

每个发布提交都必须通过 Rust release 单元测试、全 targets Clippy、构建和 Python 打包测试。新的 Direct3D 11 显示在软件渲染上与 egui 原着色器逐像素对照；适应窗口、100%、回到适应窗口和编辑（画笔、撤销、重做）的画面与 1.1.0 对照，只有个别像素差 1 级（浮点舍入）。Windows CI 与发布流程在私有桌面实际启动正式 EXE，以首帧与截图判定，覆盖缺少 DLL、强制软件渲染，以及“上次用显卡没画出第一帧 → 这次改用软件渲染”的对照。

标签工作流要求 Windows x64、Linux x64、macOS arm64 / x64 全部通过构建门禁，以及一次性 Windows runner 的普通安装包和 MSIX 生命周期回归后才创建正式 Release。MSIX 测试证书仅用于隔离 runner 中的测试副本，不是商业签名。自动测试不替代人工界面验收或商店审核。

## 下载与运行

- Windows 10 / 11 x64：也可从 Microsoft Store 安装（商店更新需微软审核后推送）。`windows-x64.zip` 为绿色版，解压后运行 `LiteView.exe`；`windows-x64-setup.exe` 为当前用户安装包，不需要管理员权限。
- Linux x64：解压 `linux-x64.tar.gz` 后运行 `./LiteView`，构建基线为 Ubuntu 22.04。
- macOS：按机器选择 `macos-arm64.tar.gz`（Apple Silicon）或 `macos-x64.tar.gz`（Intel），将 `LiteView.app` 拖入 Applications。
- 发布包附 `SHA256SUMS.txt`、安装说明和第三方许可证。绿色版通过 `LiteView.portable` 标记将配置保存在程序旁的 `config` 目录。

## 已知限制

- 上面的内存数字来自 Windows；macOS / Linux 仍用原来的显示方式，只有“不留原图像素”这部分改进。
- 打开 4800 万像素这样的大照片时，解码过程中内存会短暂升到 300 MB 以上，显示后回落；放大到 100% 时要留原图（1200 万像素约多 60 MB）。
- 软件渲染（没有可用显卡时）在 4K 屏上拖动、缩放时 CPU 占用明显更高。
- 显卡驱动在首次启动时直接崩溃的情况，第一次仍会出现“已停止工作”，再次启动才会自动改用软件渲染；卡住的旧进程不会被自动结束。
- 预算检查不是进程内存硬上限：SVG 解析/滤镜、系统解码器和并行预读仍有独立开销；进程级隔离和完整中途取消尚未实现。
- SVG 仍固定以 2048 px 栅格化，尚未随视口与缩放重绘。
- 真实 HEIC EXIF 方向及系统扩展组合、Linux/macOS 原生交互与桌面集成、屏幕阅读器和参考机性能验收仍未完成。
- 未进行 Windows 数字签名或 macOS 公证。请核对下载来源和校验值，不要关闭系统安全功能来绕过警告。
- Windows 默认应用仍需用户在系统设置中确认，不能保证所有图片格式一键设为默认。
