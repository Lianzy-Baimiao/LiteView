# LiteView v1.0.0 — 正式版

看图、简单编辑和打码，放在一个离线小工具里。v1.0.0 转为正式发布，主要使用范围为 Windows；历史 v0.x 预览版保留，不覆盖旧版本。正式版仍有下列明确限制，不代表所有后续需求或平台原生验收已经完成。

## 本版更新

- **正式版发布**：软件与 Windows 版本信息升级为 1.0.0，沿用原有偏好设置、独立安装版和绿色版的使用方式。
- **准备 Microsoft Store 渠道**：新增正式包身份的 MSIX 构建，包含100%至400%多倍率图标、中英文系统菜单和30种图片格式的清单登记。商店版还没有上架；创建产品草稿和生成 MSIX 不等于通过微软审核。
- **两个渠道互不干扰**：商店版使用独立的配置目录和单实例通道，通过 AUMID 判断当前默认处理程序；包内不再写入或删除普通版的文件关联注册。
- **干净系统更省事**：Windows MSVC 发布构建静态链接 VC 运行库，避免另装未随包附带的运行库；打包会检查相关 DLL 依赖。GNU 构建避免工具链追加重复清单，最终 EXE 要求恰好一份应用清单。
- **文件关联更清楚**：可选常用或全部格式，显示已完成数量、待设置格式；回到软件后自动刷新，不再每帧查询系统。默认状态由 Windows 关联查询接口判断。
- **保留已有设置**：格式登记改为增量操作，取消勾选不会删除已有 ProgID；升级或移动绿色版时会更新已登记格式的程序路径。移除注册需要再次确认。
- **不替用户抢默认应用**：「前往系统设置」负责登记格式并打开 Windows 默认应用页，失败时回退或给出手动路径。首次启动先选择格式，不立即写注册表；没有破解 UserChoice 或模拟系统点击。
- **文字更平滑**：Windows 英文和数字优先使用 Segoe UI，中文仍用微软雅黑 UI；调整小字号轮廓渲染，减轻 125% 缩放下笔画偏厚、边缘发硬的问题，不改字号和系统缩放。
- **修复缺失的程序图标**：Windows GNU 构建显式链接资源，补回 EXE 图标、版本信息、DPI 和长路径清单。资源编译失败会阻止构建，CI 与发布流程增加最终 EXE 的资源检查。

## 验证与发布门禁

每个发布提交都必须通过 Rust release 单元测试、全 targets Clippy、构建和 Python 打包测试。Windows 资源检查实际提取大/小图标，并验证版本、单一应用清单、PerMonitorV2、长路径及通用控件。MSIX 额外验证包身份、版本、资源、格式清单、引用路径和运行库依赖，使用微软 MakePri/MakeAppx 执行实际打包校验。

标签工作流要求 Windows x64、Linux x64、macOS arm64 / x64 全部通过构建门禁，以及一次性 Windows runner 的普通安装包和 MSIX 生命周期回归后才创建正式 Release。MSIX 测试证书仅用于隔离 runner 中的测试副本，不是商业签名。具体执行证据见本标签的 Actions；自动测试不替代人工界面、WACK 或商店审核。

## 下载与运行

- Windows 10 / 11 x64：`windows-x64.zip` 为绿色版，解压后运行 `LiteView.exe`；`windows-x64-setup.exe` 为当前用户安装包，不需要管理员权限。
- Linux x64：解压 `linux-x64.tar.gz` 后运行 `./LiteView`，构建基线为 Ubuntu 22.04。
- macOS：按机器选择 `macos-arm64.tar.gz`（Apple Silicon）或 `macos-x64.tar.gz`（Intel），将 `LiteView.app` 拖入 Applications。
- 发布包附 `SHA256SUMS.txt`、安装说明和第三方许可证。绿色版通过 `LiteView.portable` 标记将配置保存在程序旁的 `config` 目录。
- 未签名的 MSIX 提交候选不放入公共下载附件。商店通过审核后再提供商店链接；不用导入测试根证书来安装日常使用版。

## 已知限制

- 预算检查不是进程内存硬上限：SVG 解析/滤镜、系统解码器、GPU 和并行预读仍有独立开销；进程级隔离和完整中途取消尚未实现。
- SVG 仍固定以 2048 px 栅格化，尚未随视口与缩放重绘。
- 真实 HEIC EXIF 方向及系统扩展组合、Linux/macOS 原生交互与桌面集成、屏幕阅读器和参考机性能验收仍未完成。
- 未进行 Windows 数字签名或 macOS 公证。请核对下载来源和校验值，不要关闭系统安全功能来绕过警告。
- 商店版最低 Windows 10 2004 x64，仍需 Windows 10/11 人工验收与商店审核；卸载通常会删除其本地设置，用户图片不受影响。
- Windows 默认应用仍需用户在系统设置中确认，不能保证所有图片格式一键设为默认；混合 DPI、多屏和其他字体环境仍需原生验收。

详细范围、证据边界和待办见仓库 `docs/PRD.md` §15.5、`docs/TODO.md` 与 `docs/PRIVACY.md`。
