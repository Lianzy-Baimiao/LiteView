# LiteView 1.0.0 商店截图

拍摄于 2026-10-17，Windows 11 build 26200，125% DPI。每种语言四张：看图、文字和箭头编辑、框选马赛克、GIF 逐帧查看。全部为 1500 × 975 PNG。

## 来源与边界

- 使用已发布的 Windows x64 1.0.0 EXE，SHA-256：`21ddc58f7d9d9e3d5589566e725fce1fc209288bfe82018adaaac6eaf058ac6a`。该 EXE 与正式 MSIX 内的 EXE 字节相同。
- 通过程序已有的 `LITEVIEW_SCRIPT` 测试回放与 `shot` 指令截取实际客户区。没有合成应用界面、后期添加标注、修改截图像素或使用旧开发版截图。
- 本次运行的是未打包 EXE，不是已安装的 MSIX。截图展示共享的看图和编辑界面，**不作为 MSIX 安装、系统关联、Windows 10 或 WACK 验收证据**。
- 原创几何山湖、演示资料卡和轨道 GIF 由 `packaging/store_screenshots.py` 生成，随仓库采用 MIT 许可。资料卡明确标注 DEMO ONLY，号码为全零占位，邮箱使用保留域名 `example.com`，没有个人资料或网络图库内容。
- 编辑页的文字、箭头与马赛克都由应用本身完成。编辑与打码场景随后在应用中保存到新生成的演示文件，保存前后哈希不同。八次运行退出码均为 0。
- GIF 关闭自动播放，前进三帧后拍摄，界面显示第 4 / 48 帧。看图和动图工具栏仅含图标与数字，中英文截图字节相同；编辑、打码场景分别显示对应语言。
- 所有运行使用新的独立配置目录，关闭单实例和首次关联提示；没有修改用户真实设置、文件关联、已有照片或证书信任。
- 已逐项核对截图内容、文字、打码覆盖范围和保存结果。各文件哈希、输入前后哈希与退出码见 `manifest.json`。

## 复现

在 Windows 桌面会话中，使用 Python 和 Pillow（本次为 12.3.0）：

```powershell
python packaging/store_screenshots.py `
  --binary dist/release-v1.0.0-verified/binary/LiteView.exe `
  --output dist/store-screenshots-new
```

输出目录必须不存在。脚本先校验 EXE 哈希，只会覆盖自己在新目录创建的演示文件。测试回放会打开应用窗口；它不使用系统键鼠注入。截图实际尺寸取决于 DPI，本次 1200 × 780 逻辑客户区对应 1500 × 975 像素。脚本拒绝低于 1366 × 768 的结果，不会拉伸小图冒充高分辨率。

本目录的 `manifest.json` 仅把输出路径改为本目录相对文件名，截图本身未修改。初次定位打码坐标时产生的中间测试图片保留在被 Git 忽略的 `dist` 中，未用于商店。
