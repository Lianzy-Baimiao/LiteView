# 轻量内置打印方案

来源：[GitHub #1](https://github.com/Lianzy-Baimiao/LiteView/issues/1)，2026-10-19 提出。**Windows 版已按本方案实现，随 v1.3.0 发布（2026-10-23）**，实测与仍缺的验收见末节；真打印机未验收。

## 范围由来

- 2026-10-20：用户本地体验 FastStone 后认为其打印功能过重（边框、拼图等大量附加功能）。LiteView 只借鉴清晰的纸张预览，目标是“看图顺手，顺便能打印”，不是点进打印后还要学另一套软件。
- 2026-10-23 用户确定：尺寸选项为“适合页面 + 指定尺寸 + 照片尺寸快捷填写 + 按图片分辨率的实际大小”，都不裁切；首版只做 Windows。

不调用资源管理器的“打印图片”向导，不嵌入浏览器或文档渲染引擎，不依赖 FastStone。排版与预览由 LiteView 控制，实际出纸仍经 Windows 打印系统和用户安装的驱动；纸盒、双面、色彩等通过驱动自己的“打印机属性”设置。

## 首版范围

- 入口：右键菜单「打印…」与 Ctrl+P（查看和编辑模式都可用）；没有图片时禁用。打开预览，不直接打印。macOS / Linux 不显示入口。
- 布局：左边纸张预览（按真实比例画图片位置，标出打印机印不到的边缘），右边设置：打印机、纸张、方向（自动 / 纵向 / 横向，默认自动：图比较宽就横向）、尺寸、份数；「更多设置」里放边距和「打印机属性…」。
- 尺寸：
  - **适合页面**（默认）：保持比例，尽量大，完整打印。
  - **指定尺寸**：毫米，宽高锁定比例。快捷填写 5 寸（89×127）、6 寸（102×152）、A4（210×297）：按图片方向转过来，填入能放进这个框的同比例最大尺寸，不裁切。
  - **实际大小**：按图片文件记录的分辨率（JFIF / EXIF / PNG pHYs / TIFF / BMP）。文件里没有分辨率时禁用并说明。手机照片常写 72 DPI，算出来很大，照常显示尺寸和超出提示，由用户决定。
- 指定尺寸 / 实际大小超出可打印区域时，预览标红并写明超出多少、会被裁掉，可一键改用适合页面；仍允许打印（不静默裁切）。
- 显示打印尺寸与实际清晰度（PPI），低于 150 PPI 提示可能不够清晰。
- 单张单页。动图打开预览时暂停，打印当前帧并标明第几帧。编辑中打印当前合成结果（先定下进行中的笔画、选区、形状、文字），不打印磁盘上的旧图。
- 透明区域合成到白纸；使用当前显示方向（查看时的旋转 / 翻转），不再按 EXIF 二次旋转。
- 点「打印」才提交；状态依次为准备图片、提交中、已交给打印机（进入队列不等于已经印完）或失败原因；提交中可取消。
- 记住上次的打印机、纸张、方向、尺寸方式与边距；份数每次从 1 开始。驱动属性里改的设置只在本次运行内保留。
- 没有打印机或打印服务停止：给普通提示，不影响看图和启动。

首版不做：装饰边框、拼图、照片墙、多图联系表、证件照排版、海报分割、批量打印、页眉页脚、铺满裁切、专色管理、macOS / Linux 打印。

## 页面几何（`print::layout`，与平台无关）

- 单位毫米。纸张尺寸与硬件可打印区域取自打印机（方向已按 DEVMODE 转好）；有效区域 = 硬件可打印区域 ∩ 纸张四边各缩进用户边距（默认 0，即只受硬件限制）。
- 图片按纸张居中；硬件边距不对称时最小平移进有效区域。放不下（只可能是指定尺寸 / 实际大小）时保持居中并报告各边超出量。
- 预览与输出使用同一个布局结果：输出换算成设备像素，预览换算成屏幕点，不各写一套比例公式。

## 输出

- 打开对话框时冻结要打印的像素：查看模式 = 当前帧 + 显示方向（只显示着缩略图时这时解原图，与复制、另存为相同；对话框开着时换了图就关掉，免得打错）；编辑模式 = 编辑画布（`Arc` 共享，不复制）。
- 后台线程（`print::raster`）：源图在打印尺寸上超过 min(设备 dpi, 600) PPI 时用与看图相同的 Lanczos 缩小（分条算，中间结果只有一条），合成白底，转成 24 位 DIB；不够时原样交出去，放大由驱动的 HALFTONE 做（不白白多交几倍数据）。整张一次 `StretchDIBits`：分条交给 GDI 时，PDF / XPS 驱动会把每条存成单独的图，阅读器里条与条之间可能看到细缝。
- GDI：`CreateDCW`（打印机 + DEVMODE）→ `StartDocW` → `StartPage` → 剪到实际打印范围后绘制 → `EndPage` → `EndDoc`；出错或取消时 `AbortDoc` 并释放句柄。驱动不支持多份时自己重复输出页面。
- 打印机列表（`EnumPrintersW`）、纸张能力（`DeviceCapabilitiesW`）、可打印区域（`CreateICW` + `GetDeviceCaps`）都在打开对话框后才在后台查；网络打印机卡住时窗口照常响应。「打印机属性…」（`DocumentPropertiesW`）在主线程弹出驱动对话框。
- 预览：要打印的像素缩小成长边约 1024 px 的一张（与看图同样的缩小方法）；原图还在解时先画屏幕上已有的纹理。
- 开发脚本：`LITEVIEW_PRINT_OUTPUT` = 打印到文件的打印机直接写到这个路径，不弹「存到哪里」。

## 影响

- 启动与空闲：不打开对话框就不碰打印服务。程序多导入系统组件 `winspool.drv`（已加入启动测试的系统 DLL 名单）；实测空闲 30 MB、第一帧 84 ~ 105 ms，与导入前相同，所以没有改成第一次打印时才加载。
- 内存：对话框开着时多原图像素（与复制、另存为相同）和一张预览纹理；打印时临时多一张出图，提交完放掉，不常驻。1200 万像素实测：对话框开着 114 MB，打印峰值 169 MB，关掉几秒后回到 46 MB。
- 不加新依赖（`windows` crate 增加 Printing / Xps 功能）。

## 验收

1. 几何单元测试：横竖图、极宽 / 极高图、方向自动、照片尺寸快捷填写、DPI 换算、非对称硬件边距、用户边距、超出检测与超出量、非法 / 非有限 / 零尺寸输入；默认布局从不超出有效区域。
2. 出图单元测试：分条结果拼起来与整张缩放逐像素相同；透明合成白底；DIB 行对齐与自下而上的顺序；分辨率读取（JFIF 各单位、EXIF、PNG pHYs、TIFF、BMP、没有记录）。
3. 用 Microsoft Print to PDF 输出到文件（`DOCINFOW.lpszOutput`），再用系统 `Windows.Data.Pdf` 渲染：核对纸张尺寸、方向、图片位置与大小（±0.5 mm）和图案颜色，不只看 API 返回成功。没有这个打印机的机器（可能包括 CI）跳过并说明。
4. GUI 回放：Ctrl+P 打开、预览截图、改方向 / 尺寸、Esc 关闭；开关对话框前后看图与内存不受影响；编辑模式打印的是当前合成结果。
5. 真打印机验收（取消、驱动属性、份数、脱机与失败提示、实际边距）需在有打印机的机器上做；本机只有 PDF 虚拟打印机，物理打印未验收会明确写出。

## 实测（2026-10-23，本机 Windows 11，只有 Microsoft Print to PDF 与 WPS PDF 两台虚拟打印机）

- 第 1、2 条：几何 7 项、出图 3 项、分辨率读取 3 项单元测试通过。
- 第 3 条：`platform::print` 的测试打到 Microsoft Print to PDF 再用 `Windows.Data.Pdf` 渲染，横向 A4、150 × 100 mm 居中、三块颜色位置都在 ±1 mm 内。CI runner 上有没有这台打印机未验证（没有时测试跳过）。
- 第 4 条（`dist/mem-20261023/print_check.py`、`propcheck.py`）：Ctrl+P 打开预览并打印成 PDF（横向 A4、内嵌 4000 × 3000 原图）；适合页面 / 指定尺寸（从适合页面的大小开始）/ 实际大小（没有记录分辨率时说明并按适合页面）；Esc 关掉再打开；动图打出来的正是预览里的那一帧；编辑中画一笔后打印，打出来的含这一笔；窗口最小时可用（右边设置可滚动）；「打印机属性…」弹出驱动对话框，点确定后照常打印。设置里记住打印机，份数下次从 1 开始。
- 份数：Microsoft Print to PDF 报告一次只能印 1 份，份数填 2 时由程序重复输出页面，得到 2 页的 PDF。
- 回放发现并修复：在「份数」等输入框里打数字后按回车会直接打印（输入框在这一帧才放开焦点）；在输入框里按 Esc 会关掉整个对话框（egui 在帧开始就清掉焦点）。现在回车只确认这个数、Esc 只退出输入，再按回车才打印、再按 Esc 才关闭。
- 用户 2026-10-23 在本机手动打印到 PDF：正常。
- 第 5 条：未做（本机没有实体打印机）。
