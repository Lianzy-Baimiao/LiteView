LiteView 启动问题诊断工具

这是收集故障信息的工具，不是修复程序，也不是新的 LiteView 安装包。

使用方法
1. 先尝试打开 LiteView，出现问题后关闭错误提示。
2. 把整个 ZIP 解压到一个可写的文件夹，不要直接在压缩包里运行。
3. 双击 collect_windows_support.cmd。无需管理员权限，也不会打开 LiteView。
4. 脚本所在文件夹会生成 LiteView-support-日期-随机码 文件夹，里面是 support-report.json。
5. 用记事本检查报告内容后，再主动发给开发者；工具不会自动上传。

请一起说明
· 从微软商店安装，还是从 GitHub 下载的安装版/绿色版？
· LiteView 的版本是多少？
· 不打开图片也会崩溃，还是只在打开某张图片时出错？

采集内容
Windows 版本和系统位数、显卡名称和驱动版本、当前用户的 LiteView 商店包版本，以及最近 7 天应用错误事件中属于 LiteView.exe 的故障模块、异常代码与故障偏移。
最多检查最新的 500 条应用错误，只输出 LiteView 的故障签名。不输出其他软件事件。

不会做的事
不修改注册表、文件关联、证书、驱动或防护设置；不安装依赖；不读取照片、浏览器数据或完整内存；不收集用户名、设备序列号和完整文件路径；不联网上传。
启动命令的 ExecutionPolicy 参数只作用于这一次 PowerShell 进程，用于执行随附的本地脚本，不改变系统永久执行策略。工具不要求关闭 Windows 安全防护。

如果采集失败或没有匹配记录
没有记录不等于软件正常。请在开始菜单搜索“查看可靠性历史记录”，选择 LiteView 停止工作时的红叉，点“查看技术详细信息”。
发回故障模块名称、异常代码、故障偏移，或者详细信息截图；截图中如有用户名或私人文件路径，请先遮住。

隐私提示
系统和驱动版本仍属于设备信息；请先检查，再决定是否分享。不要把完整 Windows 事件日志、内存转储或私人图片直接发布到公开评论区。
